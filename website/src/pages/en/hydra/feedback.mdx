# Feedback Effects

Feedback is when the output is used as an input, making an infinite mirror effect.

## Basic feedback

### Feedback with scaling

<MiniRepl
  client:only="react"
  tune={`await initHydra()
src(o0)
  .scale(1.01)
  .blend(osc(10, 0.1, 0.5), 0.1)
  .out()
`}
/>

## The structure of a feedback patch

```javascript
src(o0)                    // 1. Take the previous frame
  .scale(1.01)             // 2. Apply a transform
  .rotate(0.01)
  .blend(source, amount)    // 3. Blend with a new source
  .out()                    // 4. Output
```

<MiniRepl
  client:only="react"
  tune={`await initHydra()
src(o0)
  .scale(1.02)
  .rotate(0.02)
  .blend(noise(3).color(1, 0, 0.5), 0.1)
  .out()
`}
/>

## Feedback tips

1. **Start with small values** (scale: 1.01, rotate: 0.01)
2. **Add decay** (brightness: -0.005)
3. **Use blend for control** (0.05-0.3)
4. **Clear the screen**: `solid(0, 0, 0).out()` if it "blew up" to white
