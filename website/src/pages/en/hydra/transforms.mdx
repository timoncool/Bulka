# Transforms

Transforms change the visual signal after a source makes it. They are **geometric** or **color** transforms.

## Geometric transforms

### rotate() — Rotation

```javascript
rotate(angle, speed)
```

<MiniRepl
  client:only="react"
  tune={`await initHydra()
osc(10).rotate(0.5).out()
`}
/>

<MiniRepl
  client:only="react"
  tune={`await initHydra()
// Constant rotation
osc(10, 0.1, 0.5)
  .rotate(() => time * 0.1)
  .out()
`}
/>

---

### scale() — Scaling

```javascript

```

<MiniRepl

<MiniRepl


<MiniRepl

/>

<MiniRepl
  client:only="react"
  tune={`await initHydra()
// The offset makes a brick wall effect

  .color(1, 0.5, 0)
  .out()
`}
/>

## Combining transforms

Transforms can be chained:

<MiniRepl
  client:only="react"
  tune={`await initHydra()
osc(10, 0.1, 0.5)
  .rotate(() => time * 0.1)
  .kaleid(4)
  .color(1, 0.5, 0.2)
  .pixelate(20, 20)
  .out()
`}
/>
