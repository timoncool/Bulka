# External Sources

Hydra can use external media: images, video, a webcam and the screen. They load into the variables `s0`, `s1`, `s2`, `s3`.

## initImage() — Image

Loads an image from a URL as a visual source.

```javascript
s0.initImage(url)
```

**Supported formats:** `.jpeg`, `.jpg`, `.png`, `.bmp`, `.gif`, `.webp`

<MiniRepl
  client:only="react"
  tune={`await initHydra()

// Load an image
s0.initImage("https://upload.wikimedia.org/wikipedia/commons/2/25/Hydra-Foto.jpg")
src(s0).out()
`}
/>

<MiniRepl
  client:only="react"
  tune={`await initHydra()

// An image with a kaleidoscope
s0.initImage("https://upload.wikimedia.org/wikipedia/commons/2/25/Hydra-Foto.jpg")
src(s0)
  .kaleid(6)
  .colorama(0.5)
  .out()
`}
/>

<MiniRepl
  client:only="react"
  tune={`await initHydra()

// An image as a modulator
s0.initImage("https://upload.wikimedia.org/wikipedia/commons/2/25/Hydra-Foto.jpg")
osc(20, 0.05, 1)
  .modulate(src(s0), 0.5)
  .out()
`}
/>

<MiniRepl
  client:only="react"
  tune={`await initHydra()

// A pixel effect with an image
s0.initImage("https://upload.wikimedia.org/wikipedia/commons/thumb/a/a7/Camponotus_flavomarginatus_ant.jpg/800px-Camponotus_flavomarginatus_ant.jpg")
src(s0)
  .pixelate(H("20 40 60"), H("15 30 45"))
  .modulate(noise(3), 0.1)
  .out()
`}
/>

## initVideo() — Video

Loads a video file from a URL as a source.

```javascript
s0.initVideo(url)
```

**Supported formats:** `.mp4`, `.ogg`, `.webm`

<MiniRepl
  client:only="react"
  tune={`await initHydra()

// Load a video
s0.initVideo("https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4")
src(s0).out()
`}
/>

<MiniRepl
  client:only="react"
  tune={`await initHydra()

// A video with a kaleidoscope
s0.initVideo("https://interactive-examples.mdn.mozilla.net/media/cc0-videos/friday.mp4")
src(s0)
  .kaleid(4)
  .colorama(0.3)
  .out()
`}
/>

## initCam() — Webcam

Starts a video stream from the webcam.

```javascript
s0.initCam(index)
```

| Parameter | Default | Description |
|----------|--------------|----------|
| index | 0 | Camera number (when there are several) |

<MiniRepl
  client:only="react"
  tune={`await initHydra()

// Webcam
s0.initCam()
src(s0).out()
`}
/>

<MiniRepl
  client:only="react"
  tune={`await initHydra()

// Camera with effects
s0.initCam()
src(s0)
  .saturate(3)
  .contrast(1.5)
  .kaleid(6)
  .out()
`}
/>

## initScreen() — Screen capture

Captures the screen, a window or a browser tab.

```javascript
s0.initScreen()
```

<MiniRepl
  client:only="react"
  tune={`await initHydra()

// Screen capture
s0.initScreen()
src(s0)
  .kaleid(4)
  .out()
`}
/>

## A complete example with music

<MiniRepl
  client:only="react"
  tune={`await initHydra()

// Load an image as a source
s0.initImage("https://upload.wikimedia.org/wikipedia/commons/2/25/Hydra-Foto.jpg")

// Visuals with the image
src(s0)
  .pixelate(H("20 40 60 80"), H("15 30 45 60"))
  .modulate(osc(3, 0.1, 0.5), H("0.1 0.2 0.3"))
  .kaleid(H("<3 4 5 6>"))
  .colorama(H("0.1 0.3 0.5"))
  .out()

// Ambient music
note("[c3 eb3 g3 bb3]/4")
  .s("sawtooth")
  .lpf(sine.range(300, 800).slow(8))
  .lpq(4)
  .room(0.8)
  .delay(0.5)
`}
/>

## Fixing CORS problems

If an image or video does not load:

1. Use services with CORS support:
   - Wikimedia Commons
   - Imgur
   - Giphy

2. For YouTube/Vimeo, use `initScreen()` to capture the browser window
