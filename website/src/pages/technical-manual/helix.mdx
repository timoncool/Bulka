# Сочетания клавиш Helix в REPL

REPL Strudel поддерживает сочетания клавиш редактора [Helix](https://helix-editor.com/) через расширение `codemirror-helix`. Helix — это постмодальный текстовый редактор, ориентированный на редактирование «сначала выделение» и работу с несколькими курсорами.

## Включение режима Helix

1. Откройте панель настроек в REPL (нажмите на иконку настроек или используйте сочетание клавиш)
2. Найдите раздел «Keybindings»
3. Выберите «Helix» из доступных вариантов

## Ключевые отличия от Vim

Helix использует подход «сначала выделение», что означает:

- **Выделение → Действие** (Helix) вместо **Действие → Перемещение** (Vim)
- Например, чтобы удалить слово в Helix: `w` (выделить слово) → `d` (удалить)
- В Vim это было бы: `dw` (удалить слово)

## Основные команды Helix

### Normal mode

- `i` — Перейти в insert mode перед выделением
- `a` — Перейти в insert mode после выделения
- `v` — Перейти в visual/select mode
- `w` — Выделить следующее слово
- `e` — Выделить до конца слова
- `b` — Выделить предыдущее слово
- `x` — Выделить/расширить строку
- `d` — Удалить выделение
- `c` — Изменить выделение (удалить и перейти в insert mode)
- `y` — Скопировать (yank) выделение
- `p` — Вставить после выделения
- `u` — Отменить
- `U` — Повторить
- `/` — Поиск
- `n` — Выделить следующее совпадение поиска
- `N` — Выделить предыдущее совпадение поиска

### Перемещение

- `h, j, k, l` — Двигаться влево, вниз, вверх, вправо
- `gg` — Перейти в начало документа
- `ge` — Перейти в конец документа
- `{` / `}` — Перейти к предыдущему/следующему абзацу
- `%` — Перейти к парной скобке

### Несколько курсоров

- `C` — Продублировать курсор на строку ниже
- `Alt-C` — Продублировать курсор на строку выше
- `,` — Убрать основной курсор
- `Alt-,` — Убрать все дополнительные курсоры

## Особенности, специфичные для Strudel

На данный момент режим Helix в Strudel предоставляет стандартные сочетания клавиш Helix. В отличие от режима Vim, пока нет специальных команд, характерных для Strudel (вроде `:w` для запуска кода).

Чтобы запустить код в режиме Helix, используйте стандартные сочетания клавиш:

- `Ctrl+Enter` или `Alt+Enter` — Запустить код
- `Alt+.` — Остановить воспроизведение

## Примечания

- Расширение `codemirror-helix` описывается как «начальная версия» и может реализовывать не все возможности Helix
- Поведение может немного отличаться от нативного редактора Helix
- Если возникнут проблемы, вы можете вернуться к другим режимам сочетаний клавиш в настройках
- Выбранный режим сочетаний клавиш сохраняется в локальном хранилище вашего браузера

## Участие в разработке

Если вы хотите добавить специальные для Strudel команды Helix (по аналогии с `:w` для запуска кода в Vim) — мы будем рады вашему вкладу! В качестве образца смотрите реализацию в `/packages/codemirror/keybindings.mjs`.
