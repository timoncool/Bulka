# Бесплатный AI — без ключа и регистрации

В Bulka встроен **бесплатный AI-агент**, который работает сразу, без API-ключа и без регистрации. Запросы идут прямо из твоего браузера в [OVHcloud AI Endpoints](https://endpoints.ai.cloud.ovh.net/) — открытый бесплатный сервис с моделями с открытыми весами (GPT-OSS, Llama, Qwen, Mistral), размещённый в ЕС. Твои данные не используются для обучения моделей.

## Быстрый старт

1. Открой вкладку **Chat** в боковой панели справа
2. Нажми на иконку настроек (шестерёнка)
3. Выбери провайдера **Бесплатно (OVHcloud)**
4. Выбери модель из списка
5. Начинай общаться с агентом!

API-ключ не требуется.

## Доступные модели

Список моделей загружается автоматически. Среди них — быстрая **GPT-OSS 20B** (по умолчанию), более умная **GPT-OSS 120B**, а также **Llama 3.3 70B**, **Qwen3** и **Mistral**. Для простых задач хватит модели по умолчанию; для сложных — выбери модель побольше.

## Ограничение бесплатного тарифа

Бесплатный доступ рассчитан на **2 запроса в минуту** (ограничение считается по твоему IP). Если упрёшься в лимит — подожди ~30 секунд и повтори. Нужно больше и стабильнее — подключи свой ключ (OpenAI, Anthropic, Gemini) или **OpenRouter** в тех же настройках.

## Инструменты агента

Не все бесплатные модели поддерживают вызов инструментов (function calling). Для них Bulka использует **текстовые маркеры действий** — агент возвращает код в блоке ```` ```javascript ```` и маркер `[PLAY]`/`[STOP]`, а Bulka сам ставит код в редактор и запускает воспроизведение. Поэтому агент работает даже на моделях без tools, пусть и проще, чем на платных провайдерах с полноценными инструментами.

## Приватность

Запрос уходит с твоего устройства напрямую в OVHcloud — Bulka не проксирует его через свой сервер и не хранит переписку на сервере (история чата лежит только в твоём браузере).
