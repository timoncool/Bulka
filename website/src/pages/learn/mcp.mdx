# MCP-сервер: рули Bulka из Claude Desktop / ChatGPT / Cursor

[Десктопная Bulka](/learn/desktop) держит **MCP-сервер прямо внутри себя**. Твой внешний AI-агент
(Claude Desktop, Cursor, ChatGPT) подключается к нему и **полностью управляет Bulka**: пишет код,
запускает и останавливает музыку, читает текущий паттерн. Это работает, пока приложение Bulka открыто.

## Подключение

Ничего запускать/устанавливать не нужно — это HTTP-MCP по адресу. Добавь в конфиг клиента и перезапусти его:

```json
{ "mcpServers": { "bulka": { "type": "streamable-http", "url": "http://127.0.0.1:4188/mcp" } } }
```

- **Claude Desktop / Cursor:** вставь этот блок в `claude_desktop_config.json` (или конфиг Cursor).
- **Claude Code:** `claude mcp add --transport http bulka http://127.0.0.1:4188/mcp`

Готовый сниппет и кнопки управления (старт/стоп/перезапуск) — в приложении, вкладка **«Настройки» → панель MCP**.

## Инструменты

- `set_code_and_play` — заменить весь код и сразу запустить (главный).
- `set_code` / `append_code` — заменить / дописать код.
- `get_code` — прочитать текущий код.
- `play` / `stop` — запуск / остановка.
- `get_new_messages` / `send_chat_message` — **чат через MCP**: читать сообщения пользователя из чата Bulka и
  отвечать в него.

## Чат через MCP (двусторонний)

В чате Bulka выбери провайдера **«Внешний агент (MCP)»** — и пиши прямо туда. Сообщения уходят внешнему агенту,
он читает их (`get_new_messages`), отвечает в чат (`send_chat_message`) и попутно рулит музыкой. Так внешний
Claude становится «мозгом» твоей Bulka.

Подробная инструкция для агента (тулы + база Strudel) — файл `desktop/bulka-mcp-skill.md` в репозитории.
