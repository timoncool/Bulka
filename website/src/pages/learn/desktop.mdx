# Десктоп-версия Bulka (Windows)

Bulka есть как **портативное Windows-приложение** — вся Bulka работает локально, в одной папке.
[Скачать последнюю версию](https://github.com/timoncool/Bulka/releases/latest).

- **Установщик** `Bulka_x64-setup.exe` → ярлык «Bulka». Ставится без прав администратора и **сам обновляется**
  с новых релизов.
- **Портатив** `Bulka-portable.zip` → распакуй → `Bulka.exe`. Ничего не пишется в систему — удалил папку,
  удалил приложение.

## Что внутри

Приложение поднимает встроенный сервер и открывает окно — полноценная Bulka без браузера. Требуется
Windows 10/11 x64 (WebView2 в Win11 уже есть; иначе установщик докачает).

## Локальность и приватность

- **Ключи и настройки** хранятся в папке приложения (`webview-data`), а не в системе. Всё локально.
- Закрыл окно — всё закрылось (сервер не висит фоном).
- Запись треков и экспорт WAV сохраняются в папку приложения (`recordings`) и папка открывается после сохранения.

## Что доступно только в десктопе

- **[Встроенный MCP-сервер](/learn/mcp)** — внешний Claude Desktop / ChatGPT / Cursor управляют Bulka.
- **[Локальные модели (LM Studio / Ollama)](/learn/local-models)** — чат Bulka на твоей локальной модели, без облака.

## Сборка из исходников

Репозиторий [timoncool/Bulka](https://github.com/timoncool/Bulka), папка `desktop/` (Tauri v2):
`bash desktop/build.sh` → установщик, `bash desktop/pack-portable.sh` → портатив. Подробности — в `desktop/README.md`.
