# Десктоп-версия Bulka

Bulka есть как **приложение для Windows, Linux и macOS** — вся Bulka работает локально.
[Скачать последнюю версию](https://github.com/timoncool/Bulka/releases/latest).

- **Windows, установщик** `Bulka_<версия>_x64-setup.exe` → ярлык «Bulka». Ставится без прав администратора и
  **сам обновляется** с новых релизов.
- **Windows, портатив** `Bulka-portable.zip` → распакуй → `Bulka.exe`. Ничего не пишется в систему — удалил папку,
  удалил приложение.
- **Linux** `Bulka_<версия>_amd64.AppImage` (любой дистрибутив, сам обновляется) или `Bulka_<версия>_amd64.deb`.
- **macOS** (Apple Silicon, macOS 13.5 и новее) `Bulka_<версия>_aarch64.dmg`. Приложение не заверено Apple: запусти
  его один раз, затем «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть». Если macOS
  пишет, что приложение повреждено, выполни в Терминале `xattr -cr /Applications/Bulka.app`.

## Что внутри

Приложение поднимает встроенный сервер и открывает окно — полноценная Bulka без браузера. Windows 10/11 x64 нужен
WebView2 (в Windows 11 он есть; иначе установщик докачает).

## Локальность и приватность

- **Ключи, настройки и записи** хранятся локально: на Windows — в папке приложения (`webview-data`, `recordings`),
  на Linux — в `~/.local/share/app.bulka.desktop`, на macOS — в `~/Library/Application Support/app.bulka.desktop`.
- Закрыл окно — всё закрылось (сервер не висит фоном).
- Запись треков и экспорт WAV сохраняются в папку `recordings`, и папка открывается после сохранения.

## Что доступно только в десктопе

- **[Встроенный MCP-сервер](/learn/mcp)** — внешний Claude Desktop / ChatGPT / Cursor управляют Bulka.
- **[Локальные модели (LM Studio / Ollama)](/learn/local-models)** — чат Bulka на твоей локальной модели, без облака.

## Сборка из исходников

Репозиторий [timoncool/Bulka](https://github.com/timoncool/Bulka), папка `desktop/` (Tauri v2):
`bash desktop/build.sh` собирает приложение под текущую ОС, `bash desktop/pack-portable.sh` — портатив Windows,
`desktop/build-linux-docker.sh` — Linux в Docker. Подробности — в `desktop/README.md`.
