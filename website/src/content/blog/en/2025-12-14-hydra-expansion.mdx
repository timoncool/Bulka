# Hydra: fixes and docs

## initImage and initVideo fixed

`initImage()` and `initVideo()` did not work before: Strudel's code parsed the URLs wrongly when passing them to Hydra, which broke loading external media.

Now it is fixed:

```javascript
await initHydra()

// Load an image as a source
await s0.initImage("https://upload.wikimedia.org/wikipedia/commons/2/25/Hydra-Foto.jpg")

src(s0)
  .saturate(2)
  .kaleid(4)
  .out()
```

```javascript
await initHydra()

// Load a video as a source
await s0.initVideo("https://example.com/video.mp4")

src(s0)
  .modulate(osc(3), 0.5)
  .out()
```
