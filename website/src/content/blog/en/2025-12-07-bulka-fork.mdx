# Bulka: a Russian fork of Strudel

Today we launched **Bulka**, a Russian-language fork of [Strudel](https://strudel.cc), the platform for live coding music in the browser.

## What's new

### Rebranding
- New name: **Bulka** (🍞)
- New logo and favicon
- Russian-language interface

### Localization
- The whole interface translated into Russian
- Russian docs and tutorials
- Built-in API reference in Russian

### Local samples
- Dirt-Samples added (~486MB)
- Tidal-drum-machines for drum machines
- 100% local playback without CORS problems

### New default track
- "Pixel Sunrise" by Nerual Dreming as the starting track
- RolandTR808 drum machines load globally
