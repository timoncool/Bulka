# Bulka AI Agent

The main update of the day is the **AI Music Agent** for vibe-coding music!

## AI Agent

### Multi-provider support
- **OpenAI**: GPT-4.1, GPT-5, GPT-5.1, o3-mini
- **Anthropic**: Claude 4.5 Sonnet, Claude Opus 4.5
- **Gemini**: Gemini 2.5 Pro, Gemini 2.5 Flash

### Features
- Chat interface in the side panel
- Tool calling to control the code
- RAG search across the docs
- Real-time response streaming
- Extended thinking for Claude
- Reasoning summaries for GPT-5.1
- Chat saved in localStorage

### Agent tools
- `runCode` — run the code
- `stopCode` — stop playback
- `updateCode` — edit the code
- `getCode` — read the current code
- `highlightCode` — highlight a selection
- `searchDocs` — search the docs
- `listSounds` — list the available sounds
